# CodeAlpha_Student-Grade-Tracker 🎓

A Java-based application designed to help teachers or students track academic performance. This project calculates the average percentage and assigns a grade based on the marks entered for various subjects.

---

## 🚀 Features
* **Dynamic Input:** Users can specify the number of subjects and enter marks for each.
* **Accurate Calculations:** Automatically computes the **Total Marks** and **Average Percentage**.
* **Smart Grading:** Assigns a letter grade (A, B, C, D, F) based on standard academic thresholds.
* **Summary Report:** Displays a clean final result including all calculated metrics.

---

## 🛠️ Technologies Used
* **Language:** Java
* **Input Handling:** `java.util.Scanner`
* **Logic:** Control flow statements (if-else) and loops for data processing.
