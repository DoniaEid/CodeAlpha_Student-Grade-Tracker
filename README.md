Student Grade Tracker 🎓
A simple and efficient Java application designed to help teachers and students manage academic performance. This tool allows users to input student grades and automatically calculates essential statistics.

🚀 Features
Grade Input: Enter grades for a set of students easily.

Statistical Analysis: * Calculate the Average score.

Find the Highest grade attained.

Identify the Lowest grade in the class.

Validation: Basic handling for grade ranges (0-100).

🛠️ Technologies Used
Language: Java (JDK 8 or higher)

Core Concepts: Control Structures, Arrays/ArrayList, and Scanner class for user input.

📋 How It Works
Run the program.

Enter the number of students.

Input the grade for each student when prompted.

The program will display the Average, Highest, and Lowest grades immediately.

💻 Sample Output
Plaintext
Enter the number of students: 3
Enter grade for student 1: 85
Enter grade for student 2: 92
Enter grade for student 3: 78

--- Statistics ---
Average Grade: 85.0
Highest Grade: 92
Lowest Grade: 78
